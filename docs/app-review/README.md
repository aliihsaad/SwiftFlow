# App Review Workspace

This folder is reserved for the Meta App Review execution package.

## Purpose

Keep all reviewer-facing assets in one place so the submission package can be built, reviewed, and updated without mixing it with general engineering notes.

## Recorded Asset Placement

When the final review video and screenshots are produced, store them here:

- `scripts/`
  - final screencast filename and transcript reference
- `evidence/`
  - screenshots used in the reviewer package
  - exported UI evidence

## Package Rule

Anything intended to be handed to Meta, shown to Meta, or used to prepare the Meta reviewer environment should be created in this folder.
